# Simple-ping

A simple Python3 ping utility using Scapy.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Alazar120/Simple-ping.git
   cd Simple-ping
   ```

2. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

```bash
python main.py <target-ip>
```

## Example

```bash
python main.py 127.0.0.1
```
